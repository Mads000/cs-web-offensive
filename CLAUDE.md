# Projektregeln für mein Spiel

## Allgemein
- Das Spiel besteht aus einer einzigen HTML-Datei.
- Die bestehende Struktur muss erhalten bleiben.
- Funktionierender Code darf nicht unnötig verändert werden.
- Keine unnötigen neuen Dateien erstellen.

## Tokens sparen
- Untersuche nur die Codebereiche, die für meine Aufgabe
  wirklich relevant sind.
- Lies nicht unnötig die gesamte HTML-Datei erneut ein.
- Vermeide wiederholte Analysen bereits verstandener Bereiche.
- Gib niemals die komplette HTML-Datei im Chat aus.
- Bearbeite die Dateien direkt, statt vollständigen Code
  im Chat auszugeben.
- Erkläre Änderungen kurz und ohne Wiederholungen.

## Neue Funktionen
- Prüfe zuerst, welche bestehenden Funktionen relevant sind.
- Nutze vorhandenen Code, statt Systeme doppelt zu erstellen.
- Füge neue Funktionen möglichst unabhängig hinzu.
- Ändere keine anderen Funktionen ohne Notwendigkeit.
- Erhalte das bestehende Design und die Spielmechaniken.
- Achte auf mögliche Konflikte mit bestehendem Code.

## Fehlerbehebung
- Untersuche zuerst die konkrete Fehlerursache.
- Ändere nur die notwendigen Stellen.
- Teste die Änderung, wenn möglich.
- Behebe keine anderen Probleme ungefragt.

## Arbeitsweise
- Arbeite in kleinen, gezielten Schritten.
- Stelle Rückfragen, wenn wichtige Informationen fehlen.
- Fasse am Ende kurz zusammen, welche Stellen geändert wurden.
- Weise auf notwendige manuelle Tests hin.
